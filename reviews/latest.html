Claude Code vs ChatGPT Codex 外部测评 B站·赋范AI课堂 / Blink / 헤이든의 전산실

100小时实测Claude Code vs ChatGPT Codex：真实结果公开

共识是两者强项不同，速度/成本与复杂工程能力在互相取舍。

查看原始测评

观察：B站测评作者在同为20美元档连续深度使用一个月后，实际感受到 Codex 更像“全家桶”型工具，而 Claude Code 更偏“单点高压”，两者在额度限制、上下文承载和真实项目使用体感上差异明显。

改变：这意味着个人开发者在同预算下选 Codex 更容易覆盖多场景日常开发，选 Claude Code 则更像把预算集中押在少数高强度编码任务上。

边界：作者明确提到两者都存在额度/配额陷阱，若你的工作流高度依赖长上下文或持续重度使用，仅看订阅价格会低估实际使用成本。

来源：B站·赋范AI课堂

观察：Blink 的第三方评测结论是：Claude Code 搭配 Claude Sonnet 4.6 更适合复杂、多步骤工程任务，而 GPT-5.1 Codex Mini 更擅长快速、聚焦的代码生成。

改变：这会直接改变团队分工与工具路由：需要连续推理、跨步骤修改的任务更适合交给 Claude Code，临时补函数、快速产出代码片段时 Codex 更省时间。

边界：这篇评测同时把 Codex 的优势限定在“快而专”的生成场景，若任务涉及长链路工程推进，Codex 未必是更稳的主力。

来源：Blink

Claude Code vs ChatGPT Codex 外部测评 B站·赋范AI课堂 / Jangwook Blog

100小时深度实测！Claude Code 巅峰对决 ChatGPT Codex 结果太真实了！

共识是：同样比能力，真正分水岭常在预算档位与接入工作流成本。

查看原始测评

观察：赋范AI课堂在同样 $20 档位连续用了 Codex 和 Claude Code 一个月，实际踩到了额度陷阱、测出了上下文差异，并认为 Codex 更像“全家桶”，Claude Code 则更偏“单点高压工具”。

改变：这意味着个人开发者在同预算下，选 Codex 更可能一套工具覆盖日常问答加编码流程；选 Claude Code 则要更关注额度消耗和把它用在高强度、单任务编码场景里。

边界：这条结论明确建立在 $20 档位和个人真实项目体验上，不足以直接外推到更高订阅档位、团队采购或企业级长周期使用。

来源：B站·赋范AI课堂

观察：Jangwook 的对比分析指出，Codex 因为直接活在 ChatGPT 里，已经在用 ChatGPT 的团队几乎零上手摩擦；而 Claude Code 更依赖终端熟练度和本地环境配置，小样本盲测也更容易放大 Codex 在“小片段任务”上的优势。

改变：这会直接改变团队落地路径：ChatGPT 已经是日常入口的团队更容易把 Codex 快速接进现有工作流，而 Claude Code 更适合愿意投入本地环境和命令行工作方式的开发者。

边界：作者同时提醒，基于盲测代码片段得出的优劣不一定能代表大仓库、长上下文或本地工具链深度协作场景。

来源：Jangwook Blog
