Qwen3.6-35B在Intel Panther Lake本地实测

共识是35B-A3B可本地跑，但速度与上下文长度仍是主要约束。

查看原始测评

观察：Habr作者本地实测 `Qwen3.6-35B-A3B-Q4_K_M` 时，生成一个网站大约需要20-30分钟，推理速度约15-20 token/s，且上下文变长后写代码速度会继续下降。

改变：这说明35B-A3B并非只能做演示级体验，而是能进入本地编码工作流，但用户需要按“可用的持续产出速度”而不是只看是否能跑起来来安排任务节奏。

边界：长上下文代码任务会明显变慢，不适合强依赖超长上下文、要求快速多轮迭代的本地开发场景。

来源：Habr

观察：Dzen的第三方分析指出，`Qwen3.6-35B-A3B` 虽然总参数为35B，但MoE架构下每个token实际只激活约3B参数，因此可以在相对更克制的本地硬件上运行。

改变：这对本地部署用户的实际意义是，35B级模型不再必然等同于高门槛显存需求，团队在选型时可以把它视作“可本地落地的35B能力档”而非纯云端模型。

边界：它降低的是运行门槛而不是消除性能代价，真实速度、量化质量和offload配置仍会决定体验，不适合把“能启动”直接等同于“高吞吐生产可用”。

来源：Дзен

Claude Code工作流实测400倍效率

外部共识是：高效率主要来自工作流设计与token管理，而非神奇提示词。

查看原始测评

观察：Medium作者在用Claude Code审一个PR时，仅3轮提示上下文就到47%，改成分层工作流后，多数流程的token消耗下降了90%以上。

改变：这说明所谓“高效率”更多来自上下文管理和任务分层，用户能把原本很快爆上下文、成本失控的代码审查和开发流程，变成更长会话、更低费用的可持续用法。

边界：这类收益依赖事先设计分层流程与上下文隔离，材料没有证明所有复杂任务都能同样幅度节省。

来源：Medium / All About Claude

观察：LinkedIn作者总结“TokenMaxxing”时提到，Sonnet默认已足够覆盖大多数编码任务，而Opus会以约4倍速度消耗套餐额度，因此他长期避免把Opus当默认选择。

改变：对真实用户的改变是，工作流优化不只是提速，还包括把“模型路由”纳入日常决策：普通编码优先便宜模型，把高成本模型留给少数高难度步骤，才能把使用时长和预算一起拉长。

边界：这种策略更适合额度敏感、追求性价比的个人或团队；如果任务本身极度依赖最强推理，优先省token可能会牺牲一次完成率。

来源：LinkedIn / TokenMaxxing

实测复现Kimi「Prefill as a Service」双卡推理

外部分析共识是：价值在资源解耦，代价在链路与系统复杂度。

查看原始测评

观察：第三方技术分析指出，Prefill-as-a-Service 的核心可行性在于把 prefill 与 decode 拆开，让 KV Cache 可以跨节点甚至跨数据中心传递，而不是强绑定在同一台推理机上。

改变：这意味着团队可以把长上下文预填充和逐 token 解码分配到不同硬件上，复现双卡拆分推理时更关注链路与 KV 传输，而不只是堆单机显存。

边界：代价是系统复杂度和链路开销会上升，这类方案更适合长上下文、高并发或资源异构场景，不一定适合低延迟、单机即可跑通的小规模部署。

来源：Norvik Tech

安卓Termux跑Ollama+Claude Code+Blender实测

共识是可跑通且门槛下降，但更像开发者实验环境，不是大众化生产力方案。

查看原始测评

观察：开发者在社区仓库中给出可复现方案，明确把Claude Code接到Termux里的Ollama来跑，并特别注明安卓端建议至少4GB内存且需要稳定网络。

改变：这意味着用户可以把安卓手机临时变成一套可用的本地AI编码环境，而不是只能在PC或云主机上接Claude Code类工作流。

边界：门槛并不低，低内存设备和网络不稳的场景容易卡在安装、模型运行或连接阶段，不适合把它当成即装即用的普通手机应用。

来源：Johndevils / claude-code-termux

观察：第三方上手文章指出，Android上通过Termux运行Ollama已经简化到可直接用`pkg install ollama`安装，作者把这件事定义为“比以前更容易上手”的本地LLM入口。

改变：对开发者和折腾型用户来说，手机侧部署本地模型的试验成本明显下降，更适合快速验证移动端离线AI、便携演示和轻量开发流程。

边界：它仍被作者定位为面向开发者和爱好者的方案，说明这套流程更适合实验和探索，不适合期待图形化、低维护成本体验的普通用户。

来源：dev.to / Running Llama3.2 on Android: A Step-by-Step Guide Using Ollama
