GPT-5.4与Claude Opus 4.6投行评测失利

外部测评共识是：能提效做初稿，但离客户直发仍有距离。

查看原始测评

观察：第三方评测者在覆盖金融、法律等44种职业真实知识工作任务的测试里，观察到GPT-5.4 Thinking得分83.0%，高于Claude Opus 4.6的78.0%。

改变：这意味着在投行这类高密度知识工作里，团队若二选一，GPT-5.4更可能先产出可供分析师修改的初稿，从而略微降低一轮人工校对负担。

边界：但该分数仍明显不是“可直接发客户”的水平，材料也未展示具体错误类型或合规风险，因此更适合做草稿与研究辅助，不适合无审阅外发。

来源：知乎《GPT-5.4深夜发布，最适合OpenClaw的天选模型登场了。》

观察：第三方深度评测在250个MCP Atlas任务中发现，GPT-5.4采用工具搜索可比全量上下文注入减少47% Token消耗且准确率不降；在包含专业任务的XSCT Bench上，其日常、专业、极限三档分差仅0.5分，表现出很强稳定性。

改变：对需要长材料检索、反复追问和多轮整理的金融工作流，这更接近“可持续使用”的特性：同等准确度下可压低上下文成本，且不同任务强度下的输出波动更小。

边界：但它在该榜单综合仅排第5，说明稳定不等于顶尖结论质量；对必须一次成稿、措辞严谨的客户材料，仍不能替代人工终审。

来源：知乎《GPT-5.4 深度评测报告》

MCP SuperAssistant外部测评 知乎专栏 / GitCode 博客

MCP SuperAssistant浏览器AI外挂上手体验

价值明确，但配置与稳定性仍是实际门槛。

查看原始测评

观察：知乎作者上手时发现，MCP SuperAssistant并不是装上即用，而是要通过浏览器插件配合本地代理，并逐项配置本地 MCP 服务及连接方式，浏览器里的网页大模型才能真正调用工具。

改变：这意味着用户可以继续用 ChatGPT/Gemini 等网页端模型，同时把本地 MCP 工具链接进浏览器工作流，不必切到桌面客户端。

边界：代价是部署链路更长、需要手动维护本地代理和 MCP 配置，不适合只想零配置体验浏览器 AI 的普通用户。

来源：知乎专栏

观察：GitCode 技术解析提到，MCP-SuperAssistant v0.3.1-alpha 的重点改进是连接稳定性和资源效率，并通过 SSE 做实时通信，说明作者关注的核心问题不是功能噱头，而是浏览器接 MCP 时是否能稳定、持续地传输上下文和结果。

改变：对实际使用者来说，稳定性和资源占用改善会直接影响浏览器里长会话、多工具串联、实时返回结果这类工作流是否可用。

边界：但该版本仍是 alpha，说明它更适合愿意尝鲜和调试的开发者，不适合对稳定性要求极高的生产场景。

来源：GitCode 博客

改变：对个人创作者和小团队来说，这代表AI出图不再只是找灵感或做草稿，而是可以承担更接近成品的视觉生产任务，减少中间返工。

边界：这类判断偏整体工作流体验总结，片段里未给出具体失败案例，因此更适合作为生产力定位参考，不足以替代细分场景测试。
