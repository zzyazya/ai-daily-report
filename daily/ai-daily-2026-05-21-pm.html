风险提醒

容易误读看到 SpecBench、RoadmapBench v2、DecisionBench 等长程 Agent 基准发布后，容易误以为高分或“99% success”已经足以证明 Coding Agent 或 RAG 系统可直接稳定用于生产。
正确理解这些论文集中强调的恰恰是评测陷阱：SpecBench关注奖励劫持，RoadmapBench v2和DecisionBench强调长周期任务的真实复杂性，而“99% Success Paradox”指出高检索成功率在 RAG 中也可能接近随机选择。对开发者来说，基准分数更像是局部能力信号，不等于真实环境下的可靠性、安全性和可控性。
建议在采纳相关 Agent 或 RAG 方案前，补做面向你自身业务的长程任务、失败恢复、作弊行为和线上数据分布偏移测试，不要只看论文榜单分数。
