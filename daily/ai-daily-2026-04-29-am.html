Claude Code五款技能插件效率实测

外部体验更集中在“先建索引再查询”提效，但部署权限是现实门槛。

查看原始测评

观察：Robo Rhythms 实测称，Graphify 作为 Claude Code skill 会先一次性读取代码文件并建立持久化知识图谱，之后可直接用自然语言查询整个代码库而不必反复重读文件。

改变：这会把插件使用方式从“每次都重新扫仓库”变成“先建索引、后连续追问”，对需要频繁理解大项目结构、依赖关系和调用链的个人开发者或团队更省时。

— Robo Rhythms

观察：OpenClaw Blog 在 Graphify 的实际使用说明里提到，它可作为 Claude Code 的 `/graphify` 命令接入，但安装阶段需要写入如 `settings.json` 之类的配置文件。

改变：这意味着技能插件并非完全即插即用，团队要把它纳入日常工作流，通常需要给当前目录或用户目录提供可写权限并允许修改本地配置。

边界：在只读工作目录、受限企业终端或不允许改写本地配置的环境里，这类技能插件的落地会受阻。

— OpenClaw Blog
