风险提醒

容易误读看到 Gemini API 的 remote MCP、Hermes Agent 的自主网页自动化、Rowboat 的本地优先替代 Claude Desktop 方案后，容易误以为“支持本地优先或托管 Agent 扩展”就等于默认安全，可以直接接入生产环境。
正确理解这类能力扩展的是 Agent 的工具调用边界，不是自动解决权限、数据泄露、提示注入和越权执行风险。无论是 Gemini API 的 remote MCP，还是 Rowboat 这类本地优先方案，都仍需单独评估认证鉴权、工具白名单、审计日志和隔离策略。
建议建议先在最小权限沙箱中做红队测试，再决定是否把 remote MCP 或自主网页自动化能力接入正式开发流。
