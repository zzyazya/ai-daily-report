DeepSeek V4 Flash接入Codex实测

接入门槛低，但需注意配置隔离与版本要求。

查看原始测评

观察：LINUX DO 开发者实测称，DeepSeek V4 Flash 正式版默认支持 responses_api，可在 Codex 中通过新增 deepseek.config.toml 指定模型、provider、responses wire_api 等方式接入。

改变：已配置多个 GPT provider 的 Codex 用户，可以用独立配置文件接入 DeepSeek，避免一键配置覆盖或扰动原有 config.toml。

边界：一键配置可能影响原有 Codex 配置，尤其不适合已经维护多 provider 配置且不想重写 config.toml 的用户。

— LINUX DO

改变：重度 Codex 用户只需配置一次，就能在命令行、桌面端和 IDE 扩展里复用 DeepSeek V4 Flash，降低多端切换成本。

边界：DeepSeek 官方模型目录要求 Codex CLI 至少 0.144.0，低版本需要先更新；发布后 API 响应一度变慢，可能影响稳定体验。

— LINUX DO
