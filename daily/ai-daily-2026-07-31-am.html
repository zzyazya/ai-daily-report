Token Saver将Claude PDF成本降90-99%

共识是先本地检索/转文本可显著降低 Claude PDF 成本。

查看原始测评

观察：ProPakistani 观察到，Token Saver 以本地 MCP 服务器形式接入 Claude Desktop，把 PDF 作为可搜索文档工具使用，而不是把整份 PDF 直接交给 Claude 处理。

改变：用户在问长 PDF 时可以只把相关片段送入 Claude，从而显著减少 PDF 带来的 token 消耗，并且文件保留在本机。

边界：材料只说明了本地检索式工作流和最高 99% 节省，并未给出不同 PDF 类型、查询复杂度下的独立基准结果。

— ProPakistani

观察：Plain English 的分析指出，Claude 处理 PDF 页面时会按图像计费，单页渲染后仅图片部分就可能约 1,500 tokens，尚未开始读取文字内容。

改变：这解释了为什么把 PDF 原样上传给 Claude 会让成本快速膨胀，也说明 Token Saver 这类先检索、再提交片段的流程主要价值在于避开整页视觉 token 开销。

边界：该文分析的是 PDF token 成本机制，并非 Token Saver 本身的实测；对需要视觉版面、图表或扫描页理解的任务，纯文本/检索式流程可能不足。

— Plain English
